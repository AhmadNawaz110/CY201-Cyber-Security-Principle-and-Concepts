Deep Dive: SQL Injection Mechanics

The Vulnerable Code Flow

// Java Backend
String query = "SELECT * FROM users 
               WHERE username = '" + req.getParameter("user") + "'";
stmt.execute(query);

Injection Payload

user = admin'--

Resulting Query

SELECT * FROM users WHERE username = 'admin'--'

The -- comments out the password check.

Parser State Machine

Input CharParser StateResult
adminInside String LiteralNormal
'Closes LiteralBreaks Context
--Comment StartIgnores Logic

Why it works

The database parser compiles the string *after* concatenation, treating user input as code.

Simulation: Blind SQLi (Boolean Based)

Extracting data without visual output by observing boolean responses.

The Logic Gate

Payload: 
id=1 AND (SELECT SUBSTRING(password,1,1) 
          FROM users WHERE username='admin') = 'a'

Extraction Step-by-Step

AttemptConditionResponseDeduction
1char == 'a'False (Normal Page)Not 'a'
............
5char == 's'True (Diff Page)First char is 's'

Simulation: Time-Based Blind SQLi

Used when boolean responses are indistinguishable.

// MySQL Payload
id=1 AND IF(ASCII(SUBSTRING(version(),1,1))=53, SLEEP(5), 0);
TimeObservationInference
0.01sResponse immediate.ASCII char is NOT 53.
5.10sResponse delayed.ASCII char IS 53 ('5').

Allows data extraction even if page content never changes.

Subdomain Takeover

Scenario

  1. Company creates subdomain sub.site.com pointing to GitHub Pages.
  2. Company deletes GitHub repo but forgets DNS CNAME.
  3. Attacker claims the GitHub repo name.
  4. Attacker serves malicious content on sub.site.com.

Risk

Can steal session cookies for the main domain if cookies are scoped to `.site.com`.

API Security: BOLA

Broken Object Level Authorization is specific to APIs.

GET /api/v1/users/123
Authorization: Bearer user_token_123

// Attacker changes ID
GET /api/v1/users/456
Authorization: Bearer user_token_123

Fix

Every endpoint must check if the authenticated user has rights to the object ID requested.

Password Storage: Technical Deep Dive

Why MD5 fails

MD5 is fast. A modern GPU can try 20 Billion MD5 hashes/second.

Bcrypt Work Factor

Bcrypt uses "cost" parameter (e.g., 12).

2^12 iterations.
// Slows GPU to ~10,000 hashes/sec.

Peppering

Adding a secret key (pepper) to the password before hashing, stored separately from DB.

hash = bcrypt(password + pepper, 12);

HSTS: Strict Transport Security

Strict-Transport-Security: max-age=31536000; includeSubDomains; preload

SSL Stripping Attack

Attacker downgrades connection from HTTPS to HTTP during initial handshake.

HSTS Defense

Browser remembers to *force* HTTPS for the domain, ignoring any HTTP links.

Incident Response Basics

  1. Preparation: Have a plan, contact list, and forensic tools ready.
  2. Identification: Detect the breach via SIEM alerts or user reports.
  3. Containment: Isolate affected systems (Disconnect network, block IPs).
  4. Eradication: Remove malware, patch the vulnerability.
  5. Recovery: Restore from clean backups, monitor closely.
  6. Lessons Learned: Update policies and training.

API Security Checklist

  • Authentication: JWT validation, strong secrets.
  • Authorization: Scope checks on every endpoint.
  • Rate Limiting: Prevent scraping/brute force.

Summary

  • Input Validation: Never trust user data.
  • Broken Access Control: Verify permissions on every request.
  • Crypto: Use modern standards (TLS 1.3, bcrypt).

  • Supply Chain: Monitor dependencies.
  • Mindset: Think like an attacker.
