## 2. Course Description

This course introduces the fundamental principles, concepts, and practices of cybersecurity. It provides students with a broad understanding of the cyber threat landscape, security principles, and protective mechanisms used across modern computing environments.

The course covers core topics such as the CIA triad, cyber threats and attack vectors, cryptography and encryption, network security, social engineering, web security, operating system security, mobile security, digital forensics, cloud security, risk management, incident handling, identity and access management, IoT security, application security, cyber threat intelligence, security policies, and compliance.

The course also includes a project-based component in which students present case studies, demonstrate practical understanding, and prepare a report or conference-style paper.

---

## 3. Course Objectives

The objectives of this course are to:

1. Introduce the fundamental principles and concepts of cybersecurity.
2. Explain common cyber threats, attack vectors, and security countermeasures.
3. Develop understanding of cryptographic principles, network security, and secure communication.
4. Explore security concerns in web applications, operating systems, mobile devices, cloud environments, IoT, and embedded systems.
5. Provide foundational knowledge of digital forensics, risk management, incident response, and business continuity.
6. Understand identity and access management, authentication methods, and authorization principles.
7. Introduce security governance, compliance, audits, and policy development.
8. Develop practical understanding through case studies, project work, and presentation activities.

---

## 4. Course Learning Outcomes

After successful completion of this course, students should be able to:

### CLO-1: Understand Cybersecurity Fundamentals
Explain core cybersecurity concepts, including the CIA triad, security principles, threat actors, and attack vectors.

### CLO-2: Identify and Analyze Cyber Threats and Attacks
Identify common cybersecurity threats and analyze attack techniques such as social engineering, network attacks, web attacks, cryptographic attacks, and mobile security risks.

### CLO-3: Apply Security Controls and Best Practices
Apply fundamental security controls and best practices in networking, web security, operating systems, mobile devices, cloud environments, and IoT systems.

### CLO-4: Understand Governance, Risk, and Incident Management
Explain risk management, incident response, disaster recovery, business continuity, compliance, audits, and security policy development.

### CLO-5: Communicate Security Concepts through Projects and Case Studies
Demonstrate cybersecurity understanding through case studies, project presentations, viva, and written reporting or conference paper writing.

## 5. Course Modules

### Module 1: Introduction to Cyber Security
- Overview of cyber security
- Cyber threats and attack vectors
- CIA triad

### Module 2: Cryptography and Network Security
- Privacy concepts
- Principles of cryptography
- Public Key Infrastructure (PKI)
- Cryptographic attacks
- Network basics
- Protocols and OSI model
- Firewalls, IDS, and IPS
- Virtual Private Networks (VPNs)

### Module 3: Human-Centered Security
- Social engineering
- Phishing
- Vishing
- Tailgating
- Dumpster diving
- Shoulder surfing
- Eavesdropping
- Public hotspot attacks
- QR code attacks

### Module 4: Web Security
- Web application security
- Secure coding principles
- Browser security
- HTTPS

### Module 5: Operating System and Mobile Security
- Securing Windows, Linux, and macOS
- Access controls and permissions
- Patch management
- Mobile device security
- Mobile application security
- Mobile Device Management (MDM)

### Module 6: Digital Forensics and Cloud Security
- Introduction to digital forensics
- History and standards of digital forensics
- Fundamentals of digital forensic investigations
- Cloud computing security basics
- Securing cloud infrastructure
- Best practices for securing cloud environments
- Shared responsibility model

### Module 7: Risk Management and Incident Handling
- Definition of risk
- Risk management process
- Incident response
- Disaster recovery
- Business continuity
- Physical security

### Module 8: Identity and Access Management
- IAM fundamentals
- Identity and access management principles
- Authentication methods
- Multi-factor authentication
- Biometrics
- Authorization and access control

### Module 9: IoT, Embedded Systems, and Application Security
- IoT security challenges
- Risks and vulnerabilities in IoT

- Secure Software Development Lifecycle (SDLC)

### Module 10: Cyber Threat Intelligence
- Threat intelligence fundamentals
- Understanding threat intelligence

### Module 11: Security Policies, Compliance, and Audits

### Module 13: Case Study and Project Presentation
